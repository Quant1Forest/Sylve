# Assemblage de index.html
#
# index.html se fabrique en recopiant ce fichier ligne à ligne, dans l'ordre :
#   « @chemin »  est remplacée par le contenu de sources/chemin ;
#   « # … »      est un commentaire, elle ne passe pas ;
#   tout le reste passe tel quel, lignes vides comprises.
# Les balises, et l'enveloppe des blocs de code découpés en plusieurs
# morceaux, vivent donc ici : un morceau ne contient que son langage.
#
#   node outils/construire.js
#
